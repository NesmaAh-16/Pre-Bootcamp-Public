# Python String Fundamentals

A collection of basic Python scripts demonstrating essential string operations, formatting techniques, and built-in string methods. This repository serves as a reference for handling strings and data types in Python.

## 🚀 Features

This project covers the following Python concepts:
- **Variable Assignment:** Storing strings and integers.
- **Output Methods:** Printing using multiple arguments and string concatenation.
- **Data Type Conversion:** Safely converting integers to strings for output.
- **String Formatting:** Modern approaches using `.format()` and **f-strings** (formatted string literals).
- **String Methods:** Deep dive into built-in methods like `.upper()`, `.split()`, `.isalnum()`, and more.

## 🛠️ Tech Stack
- **Language:** Python 3.x

## 📋 Code Breakdown

1. **Basic Printing:** Demonstrates printing variables vs. literal strings.
2. **Concatenation:** Combining strings using the `+` operator.
3. **Type Handling:** shows how to handle `TypeError` when mixing strings and integers.
4. **Formatting:** Compares `.format()` with the modern `f-string` syntax.
5. **String Analysis:** Practical usage of boolean string checks (e.g., `isdigit`, `isalpha`).
