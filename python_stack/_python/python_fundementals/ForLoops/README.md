# Python Fundamentals: Loops & List Algorithms

This repository contains a series of Python scripts designed to practice core programming logic. It is divided into two main sections: basic iterative loops and advanced list manipulation functions.

## 📌 Project Overview

### Section 1: Basic Iterators
- **Range Exploration:** Using `range()` with different start, stop, and step values.
- **Conditional Logic:** Implementation of "Coding Dojo" (a variation of FizzBuzz).
- **Summation:** Efficiently calculating large sums using steps vs. conditional checks.
- **Dynamic Loops:** Using variables to control loop parameters.

### Section 2: List Functions & Analysis
- **In-place Modification:** Functions that modify lists directly (e.g., `biggie_size`).
- **Statistical Analysis:** Manual implementation of `sum`, `average`, `min`, and `max` to understand underlying algorithms.
- **Data Structuring:** The `ultimate_analysis` function demonstrates how to return structured data (dictionaries) from a list.
- **Algorithm Optimization:** In-place list reversal using the "two-pointer" technique.

## 🛠️ Technical Concepts Used
- **Modulo Operator (`%`):** For divisibility checks.
- **Accumulator Pattern:** For summing and counting data.
- **Two-Pointer Technique:** For efficient, memory-friendly list reversal.
- **Modularity:** Reusing functions within other functions for cleaner code.

## 🚀 Key Learning
This project highlights the difference between **efficiency** (skipping numbers in a range) and **brute force** (checking every number with an `if` statement).
