# Python: Nested Data Structures & Custom Generators

This project demonstrates advanced handling of Python's core data structures. It includes a custom implementation of a random integer generator and various methods for traversing and manipulating complex, nested data (Lists and Dictionaries).

## 🚀 Key Features

- **Custom Random Logic:** A `randInt` function built from the ground up using `random.random()`, featuring custom logic for handling default parameters and range calculations.
- **Deep Data Manipulation:** Examples of updating values deep within nested lists and dictionaries.
- **Dynamic Dictionary Iteration:** 
  - `iterateDictionary`: Formats and prints key-value pairs from a list of dictionaries.
  - `iterateDictionary2`: Extracts specific values based on a provided key.
- **Complex Object Reporting:** `printInfo` function that handles dictionaries containing lists, providing structured summaries (counts and itemized lists).

## 🛠️ Technical Concepts
- **Default Parameters:** Handling `None` values in function arguments.
- **Nested Indexing:** Accessing data using `list[index][key]` and `dict[key][index]`.
- **String Formatting:** Using f-strings and `.join()` for clean console output.
- **Membership Testing:** Using the `in` keyword to verify keys exist before access.

## 📋 Examples Included
1. Updating multi-dimensional arrays.
2. Modifying values in a list of dictionaries.
3. Looping through "Dojo" location and instructor data.
